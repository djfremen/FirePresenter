# Changelog

## 0.1.0 — 2026-10-08

Initial open-source FirePresenter release, extracted from the TV Deck Presenter prototype.

- Independent application ID `org.firepresenter.app` and FirePresenter branding.
- Original MIT-licensed graphics, video, and PowerPoint demo files.
- Internal slide links on bundled hotspots and PowerPoint text, shapes, and pictures.
- Remote focus for slide links and presentation controls; pointer background click to advance.
- Offline local media playback and saved `.pptx` import over local Wi-Fi.
- Configurable bundled video rectangles and automatic return to a holding slide.
- Prominent documentation and in-app instructions for offline launch through Settings / Applications.
- Browser regression tests, Android build checks, license notices, and contributor instructions.
